# Mail AI — Intelligent Business Email Classification

A complete college engineering capstone project implementing an intelligent, Machine Learning-driven web application for business email triage, urgency detection, security risk scoring, and automated department routing.

Please see [`mail-ai/README.md`](file:///c:/Users/HP/OneDrive/Desktop/my%20project/mail-ai/README.md) for full project documentation and API reference.

## Quick Start
```bash
# Run from workspace root
python app.py

# Or run from inside mail-ai/
cd mail-ai
python app.py
```
Open [http://127.0.0.1:5000](http://127.0.0.1:5000) in your web browser.
